# online_store
Приложение представляет собой платформу интернет-магазина, в которой приведены товары, разделенные на категории,
с указанием основных свойств позиций.
## Установка и использование
Чтобы установить и запустить проект, нужно выполнить следующие действия:
* клонировать репозиторий, использовав ссылку с аккаунта GitHub;
* установить poetry командой pip install poetry;
* установить зависимости, введя poetry install;
* активировать виртуальное окружение командой poetry init;
* запустить приложение с помощью python main.py
### Доступный функционал
В проекте реализовано два класса:
* Product (".\src\product.py") - товары;
* Category (".\src\category.py") - категории товаров.
Для класса Product предусмотрены два наследуемых класса Smartphone (смартфоны) и LawnGrass (газонная трава),
которые принимают свойства родительского класса и дополнительно получают собственные.
В рамках класса Product реализованы следующие методы, расположенные по адресу ."\src\product.py":
* __init__ - инициализация свойств класса;
* price - геттер для получения цены, сеттер для установки цены с проверкой и подтверждением понижения;
* __str__ - строковое представление продукта;
* __add__ - сложение продуктов с проверкой соответствия классов;
* new_product - класс-метод для создания объекта Product из словаря с проверкой дубликатов;
В рамках класса Category реализованы следующие методы, расположенные по адресу ."\src\category.py":
* __init__ - инициализация свойств класса;
* add_product - добавление товаров в категорию с проверкой соответствия класса;
* products - геттер, возвращающий список товаров в заданном формате;
* get_products - метод для получения списка объектов продуктов;
* __str__ - строковое представление категории;
Также для класса Category реализован итератор, который позволяет перебирать товары в категории (расположен 
по адресу."\src\category_iterator.py").
Разработаны тесты для проверки правильности работы функционала. Тесты расположены в папке Tests в корневом
каталоге проекта. Функционал интернет-магазина в процессе разработки.
## Пример использования
После запуска приложения пользователю будет предложено меню с указанием страниц с товарами, предусмотрена
возможность сортировки позиций по категориям. При переходе к определенному товару можно изучить информацию о
свойствах продукта. При необходимости, администратор может добавлять товары. Количество товаров по позициям
и категориям рассчитывается автоматически, с помощью реализованных в проекте методов.
